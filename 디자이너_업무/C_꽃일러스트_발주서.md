# C. 꽃 일러스트 발주서 (200종)

> 도감에 등록되는 꽃 200종의 일러스트 발주 명세.
> 대상 목록: `꽃도감/일러스트_발주목록.csv` (배치·순번·파일명·특징까지 정리됨)
> 종별 상세 정보: `꽃도감/꽃목록_200종.csv`

---

## 1. 이 일러스트가 쓰이는 곳

같은 그림이 4가지 크기로 쓰인다. **가장 작은 크기에서 종이 구별되는 것이 최우선 요구사항**이다.

| 사용처 | 표시 크기 | 요구 |
|---|---|---|
| 도감 그리드 셀 (화면 04) | **약 100×100** | 이 크기에서 꽃 종류가 구별돼야 한다 |
| 도감 상세 히어로 (화면 05) | 약 132×132 | 주역. 디테일이 보이는 크기 |
| 최근 발견 · 추천 (화면 04·22) | 약 68×68 | 축소 내구성 |
| 랭킹 대표 꽃 · 아바타 (화면 17·18) | **약 32×32** | 최소 크기. 형태 실루엣만 남는다 |

> 위 4크기를 모두 만족해야 하므로, **디테일보다 형태와 색의 식별성**이 중요하다.
> 작업 중 100% / 30% 두 배율을 항상 함께 보며 그릴 것을 권한다.

## 2. 규격

| 항목 | 값 |
|---|---|
| 형식 | **SVG** (벡터) — 4가지 크기 대응 때문 |
| 아트보드 | **512 × 512** 정사각 |
| 안전 여백 | 사방 **32px** (꽃이 480×480 안에 들어오게) |
| 배경 | **투명** (배경색은 앱이 넣는다) |
| 파일명 | `flower_{도감번호 3자리}_{꽃이름}.svg` 예: `flower_081_장미.svg` |
| 색상 | RGB. 그라디언트 사용 가능하되 3스톱 이하 |
| 획 | 가능하면 **패스로 변환** (stroke 유지 시 확대·축소에서 굵기가 어긋난다) |
| 텍스트 | 사용 금지 (꽃 이름은 앱이 렌더) |
| 파일 크기 | 종당 **30KB 이하** 권장 (200종 = 6MB 이하) |
| 패스 수 | 종당 **60개 이하** 권장 (그리드 200셀 렌더 성능) |
| 추가 산출 | PNG **1x/2x/3x** (@512·1024·1536) 일괄 내보내기 |

## 3. 아트 방향

기획서 3장의 타깃(40~50대 여성, 산책·기록 정서)에 맞춘다.

### 지향
- **평면적이고 단정한 벡터 일러스트.** 식물도감의 정확성과 앱 아이콘의 단순함 사이.
- 꽃 한 송이 또는 소규모 군집 중심. **잎과 줄기는 종 구분에 필요한 최소한만.**
- 정면 또는 살짝 측면. 사용자가 촬영하는 각도와 일치시킨다.
- 색은 실제 꽃 색을 따른다. 도감이므로 **정확성이 스타일보다 우선.**

### 지양
- 사실적 렌더링·수채 텍스처 (200종 일관성 유지 불가, 축소 시 뭉개짐)
- 캐릭터화·의인화 (눈·표정 금지)
- 두꺼운 검정 외곽선 (32px에서 형태가 다 막힌다)
- 복잡한 배경·그림자 (투명 배경 원칙)
- 종마다 다른 화각·구도 (그리드에서 통일감이 깨진다)

### 통일 규칙 (200종 전체)
1. **꽃 크기 비율** — 아트보드 대비 꽃이 차지하는 비율을 종마다 맞춘다. 실제 꽃 크기(민들레 vs 해바라기)를 반영하지 않는다. 그리드에서 크기가 들쭉날쭉해 보이면 안 된다.
2. **광원** — 좌상단 고정.
3. **채도** — 동일 수준. 특정 종만 튀지 않게.
4. **군집 표현** — 군집으로 피는 종(개망초·조팝나무 등)은 3~5송이로 통일.

### 참고 캘리브레이션 `착수 전 필수`
먼저 **아래 5종만 시안으로 작업하고 승인받은 뒤** 나머지를 진행한다. 200종을 다 그린 뒤 방향이 틀리면 복구가 불가능하다.

| 도감번호 | 이름 | 선정 이유 |
|---|---|---|
| 081 | 장미 | 겹꽃잎 — 복잡한 형태의 상한선 |
| 101 | 개망초 | 작은 군집 — 축소 내구성 시험 |
| 005 | 벚꽃 | 나무꽃 — 가지 처리 기준 |
| 112 | 나팔꽃 | 나팔형 — 입체 형태 처리 기준 |
| 199 | 억새 | 꽃이 아닌 꽃이삭 — 예외 처리 기준 |

## 4. 배치 · 발주 순서

전체를 한 번에 받지 않고 **3배치로 나눈다.** 배치 1이 끝나면 앱에 붙여 실제 화면에서 검증할 수 있다.

| 배치 | 종수 | 성격 | 필요 시점 |
|---|---|---|---|
| **배치 1** | **59종** | 전국 어디서나 흔한 종 + 온보딩 추천에 쓰이는 종 | **출시 필수 · 최우선** |
| **배치 2** | **76종** | 계절마다 흔히 보이는 종 | **출시 필수** |
| **배치 3** | **65종** | 보통~귀함, 특정 지역·시기 종 | 출시 후 순차 가능 |

> 배치별 종 목록은 `꽃도감/일러스트_발주목록.csv`의 `배치` 컬럼에 있다 (배치·계절·번호 순으로 정렬됨).

**배치 3을 출시 후로 미룰 수 있는 이유** — 해당 종은 희귀도가 `보통`~`귀함`이라 출시 초기에 발견될 확률이 낮다. 미보유 상태에서는 실루엣으로 표시되므로 일러스트가 없어도 도감이 성립한다. 단, **발견 시점에는 반드시 있어야 하므로** 출시 후 1~2개월 내 완료를 전제한다.

## 5. 오인식 주의 종 `중요`

AI 판별 난이도가 `상`인 **51종**은 유사종과 형태가 거의 같다. 사용자는 도감에서 이 그림을 보고 자기가 찍은 꽃이 맞는지 판단한다. 따라서 **일러스트가 구분 포인트를 드러내야 한다.**

`꽃목록_200종.csv`의 `AI난이도`, `비슷한꽃`, `비고` 컬럼을 참고한다.

주요 그룹과 구분 포인트:

| 그룹 | 종 | 일러스트에서 살릴 것 |
|---|---|---|
| Prunus속 | 벚꽃 / 매화 / 살구꽃 / 복사꽃 / 자두꽃 | **꽃자루 길이**(벚꽃 길고 매화 거의 없음), 꽃잎 끝 갈라짐(벚꽃) |
| 진달래류 | 진달래 / 철쭉 / 영산홍 | **잎 동반 여부** — 진달래는 꽃만, 철쭉은 잎과 함께 |
| 국화과 노란 꽃 | 씀바귀 / 고들빼기 / 뽀리뱅이 / 민들레 | 꽃 크기 비율, **잎 모양** |
| 쑥부쟁이류 | 쑥부쟁이 / 벌개미취 / 개미취 | **잎 형태와 꽃 크기** |
| 개망초류 | 개망초 / 망초 | **혀꽃 길이** — 개망초는 뚜렷, 망초는 거의 없음 |
| 수국류 | 수국 / 산수국 / 나무수국 | **꽃차례 형태** — 산수국은 가장자리만 장식꽃 |
| 백합류 | 참나리 / 백합 | **검은 반점** (참나리) |
| 붓꽃류 | 붓꽃 / 꽃창포 / 노랑꽃창포 | 꽃잎 무늬와 색 |

> 이 51종은 작업 시 **유사종을 나란히 놓고 확인**해 주세요. 서로 구별되지 않으면 도감 기능 자체가 무의미해집니다.

## 7. 검수 기준

납품 시 아래를 확인한다.

| # | 항목 |
|---|---|
| 1 | **32×32로 축소했을 때** 다른 종과 구별되는가 |
| 2 | 100×100 그리드에 20개 나란히 놓았을 때 크기·채도가 균일한가 |
| 3 | 유사종끼리 나란히 놓았을 때 구분되는가 (§5의 51종) |
| 4 | 배경이 투명한가 |
| 5 | 파일명이 규칙과 일치하는가 (도감번호 3자리) |
| 6 | 파일 크기 30KB 이하, 패스 60개 이하 |
| 7 | 흰 배경·검은 배경 양쪽에서 형태가 보이는가 (흰 꽃 46종 주의) |
| 8 | 대표색 컬럼과 실제 그림 색이 일치하는가 |

> **7번 주의** — 흰색 꽃이 다수다. 흰 배경에서 사라지지 않도록 연한 외곽선 또는 명도차 처리가 필요하다.

## 8. 공수 · 일정 (참고)

| 배치 | 종수 | 종당 소요 (가정) | 소요 |
|---|---|---|---|
| 캘리브레이션 5종 | 5 | 사전 협의 | 3~5일 |
| 배치 1 | 59 | 1.5~2시간 | 12~15일 |
| 배치 2 | 76 | 1.5~2시간 | 15~19일 |
| 배치 3 | 65 | 1.5~2시간 | 13~16일 |

> 종당 소요는 스타일 확정 후 캘리브레이션 5종의 실측으로 재산정한다.
> 단순한 종(민들레·토끼풀)과 복잡한 종(장미·국화)의 차이가 크므로 평균으로 잡았다.
> **B(UI 디자인)와 완전 병행 가능**하므로 프로젝트 시작 시점에 함께 착수하는 것이 유리하다.
> 200종은 물량이 크므로 **여러 명이 나눠 작업할 경우** §3 통일 규칙과 캘리브레이션 5종 준수가 특히 중요하다.
