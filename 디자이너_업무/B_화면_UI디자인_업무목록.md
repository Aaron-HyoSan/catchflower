# B. 화면 UI 디자인 업무 목록

> 와이어프레임 23장을 실제 UI 디자인으로 옮기는 작업 목록.
> 입력물: `와이어프레임/*.svg` (23장) + `디자이너_업무/A_문구·버튼_스펙.md`
> 산출물: Figma 파일 1개 (디자인 시스템 + 화면 + 프로토타입)

---

## 공통 전제

| 항목 | 값 |
|---|---|
| 대상 플랫폼 | iOS · Android (동일 디자인, OS 관용 요소만 분기) |
| 기준 해상도 | **375 × 812** (iPhone 논리 해상도) |
| 대응 필요 폭 | 320 (SE) / 375 (기준) / 430 (Pro Max) |
| 안전 영역 | 상단 44 / 하단 34 확보 |
| 하단 내비 | 높이 64 + 홈 인디케이터 영역 24 |
| 최소 터치 영역 | 44 × 44 |
| 최소 본문 크기 | 12pt (보조 정보 10.5pt) |
| 아이콘 | 라인 아이콘, 굵기 1.6~1.8px 통일 |
| 전달 방식 | Figma 공유 링크 + Dev Mode 활성화 |

**타깃 제약 (40~50대 여성)** — 아래는 취향이 아니라 요구사항이다.
- 얇은 폰트 굵기(Light/Thin) 사용 금지. 본문은 Regular 이상.
- 저채도 회색 글자(#999 이하)를 본문에 쓰지 않는다. 명도 대비 **4.5:1** 이상 확보.
- 아이콘 단독 버튼 금지. 텍스트 라벨 병기.
- 제스처 전용 기능 금지. 스와이프로만 되는 동작은 버튼도 함께 제공.

## B-1. 디자인 시스템 구축 `선행 필수`

다른 모든 작업의 전제. 이것 없이 화면부터 그리면 재작업이 발생한다.

| # | 산출물 | 상세 |
|---|---|---|
| 1-1 | 컬러 팔레트 | Primary / 배경 / 표면 / 테두리 / 텍스트 3단계 / 상태색(성공·경고·오류). **꽃 앱이므로 Primary 색 선정 시 200종 일러스트와 충돌하지 않는 색을 골라야 한다** — 일러스트가 다채로우므로 UI는 저채도 권장 |
| 1-2 | 타이포 스케일 | A 문서 §1의 7단계를 Figma 텍스트 스타일로 등록 |
| 1-3 | 버튼 컴포넌트 | Primary / Secondary / Ghost / Small / Text / Disabled × (기본·눌림·비활성) |
| 1-4 | 폼 컴포넌트 | 입력창 / 검색창 / 라디오 / 토글 / 칩(선택·미선택) / 글자수 카운터 |
| 1-5 | 카드 컴포넌트 | 도감 셀(수집·미발견) / 기록 카드 / 랭킹 행 / 장소 프리뷰 카드 |
| 1-6 | 하단 내비 | 5탭 + 중앙 돌출 촬영 버튼(지름 68). 활성·비활성 상태 |
| 1-7 | 아이콘 세트 | ✅ **납품됨 2026-08-09 — 44종 (발주 17종보다 많다)**. `아이콘/앱아이콘 + 앱내아이콘/*.png` · 512×512 RGBA. ⚠️ **발주서의 "라인 아이콘 1.6~1.8px"이 아니라 컬러 아이콘이다**(초록·분홍 그라데이션 + 흰 디테일) → **단색 틴트를 씌우면 안 된다.** 파일명이 한글이라 `res/`에 못 넣는다(일러스트와 같은 이유) → `assets/icon/`으로 빌드가 복사한다. **44개 중 AOS가 쓰는 것은 7개**(탭 4 + 촬영 + 권한 2) — 나머지는 **쓰는 자리가 없어서 넣지 않았다**(좋아요·댓글·배지·시즌·초대 등은 예선 범위 밖 기능이고, `뒤로`·`닫기`·`취소`는 A 문서 1절 44번 **"아이콘만 있는 버튼은 만들지 않는다"** 때문에 지금 텍스트 버튼이다). 🔴 **안 쓰는 아이콘을 자리부터 만들어 넣지 않는다** — 눌러도 아무 일 없는 버튼이 이 저장소가 반복해서 지적한 결함이다 |
| 1-8 | 배지·칭호 프레임 | 배지 원형 프레임 + 칭호 칩. **B-9와 연동** |
| 1-9 | 오버레이 | 토스트 / 바텀시트 / 확인 다이얼로그 / 로딩 |
| 1-10 | 빈 상태 일러스트 | 4종 (도감 0종 / 지도 기록 없음 / 친구 없음 / 필터 결과 0) |

> **공수**: 5~7일

| 05 도감 상세 | `05_도감상세.svg` | 중간 | 히어로 일러스트 + 속성 칩 + 발견 기록 리스트 |
