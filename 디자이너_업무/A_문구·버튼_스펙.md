# A. 와이어프레임 문구 · 버튼 스펙

> 캐치플라워 앱에 들어가는 **모든 화면 문구와 버튼 텍스트**의 확정안.
> 와이어프레임(`와이어프레임/*.svg`)에 실제로 그려진 문구와 1:1 일치한다.
> 디자인 작업 시 이 문서의 문구를 그대로 사용하고, 임의로 줄이거나 바꾸지 않는다.

---

## 0. 문구 작성 원칙

주 타깃이 **40~50대 여성**이라는 점이 모든 문구 판단의 기준이다.

| 원칙 | 하지 않는다 | 한다 |
|---|---|---|
| 게임 용어를 앞세우지 않는다 | 퀘스트, 미션, 랭킹업, 컬렉션 | 꽃 모으기, 순위, 도감 |
| 시스템 어투를 쓰지 않는다 | "인식 실패", "처리 중", "오류 발생" | "알 수 없었어요", "보고 있어요" |
| 실패를 사용자 잘못으로 만들지 않는다 | "잘못 촬영하셨습니다" | "다시 한 번 찍어 주시겠어요?" |
| 동작을 지시한다 | "적절한 거리에서 촬영" | "네모 안에 꽉 채워 주세요" |
| 규칙은 이득으로 설명한다 | "시즌 점수 증가 없음" | "사진은 도감에 쌓여요" |
| 외래어는 대중 인지명만 | 컬렉션, 피드, 프로필 편집 | 도감, 기록, 프로필 수정 |
| 숫자는 단위까지 | "37" | "37종", "4회", "47일 남음" |

**어미 통일** — 안내문은 `~어요/~아요` (부드러운 구어), 버튼은 명사형 또는 `~기` (`공유하기`, `다시 찍기`).
경어 `~하십시오`, `~하시겠습니까` 는 쓰지 않는다.

## 1. 버튼 · 텍스트 스타일 정의

디자이너가 컴포넌트로 만들어야 하는 최소 단위.

### 버튼

| 종류 | 용도 | 사양 | 예시 |
|---|---|---|---|
| Primary | 화면의 주 행동, 화면당 1개 | 높이 **56px**, 라운드 완전(28px), 채움, 굵게 15~16pt | `네, 맞아요` `공유하기` |
| Secondary | 대안 행동 | 높이 **54~56px**, 테두리 1.5px, 흰 배경, 굵게 15~16pt | `아니에요, 다시 찍을게요` |
| Ghost | 회피·보조 | 높이 50px, 연한 회색 배경, 중간 굵기 15pt | `나만 보기` `나중에 할게요` |
| Small | 카드 내부 | 높이 32~40px, 12~13.5pt | `길찾기` `추가` `초대하기` |
| Text | 최소 강조 | 굵게 13pt, 밑줄 없음 | `공유하지 않기` `전체 보기` |
| Disabled | 조건 미충족 | 회색 배경 + 회색 글자, 문구를 안내로 교체 | `동네를 선택해 주세요` |

- **최소 터치 영역 44×44px**. 아이콘 단독 버튼도 이 값을 지킨다.
- 아이콘만 있는 버튼은 만들지 않는다. **반드시 텍스트를 병기**한다 (`좋아요 12`).

### 텍스트

| 역할 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| 화면 제목 | 19~21pt | Bold | 헤더 `내 꽃 도감` |
| 축하/질문 대상 | 24~32pt | Bold | `장미`, `연남동 4위` |
| 섹션 제목 | 13.5~14.5pt | Bold | `최근 발견한 꽃` |
| 본문 | 12~13.5pt | Regular | 설명문 |
| 보조 설명 | 10.5~11.5pt | Regular | 회색 부연 |
| 최소 크기 | **10.5pt** | - | 이보다 작게 쓰지 않는다 |

> 노안을 고려해 본문 최소 12pt를 권장한다. 10.5pt는 날짜·개수 등 보조 정보에만 쓴다.

### B-5 하루 중복 안내 (2026-08-05 추가 · iOS 세션)

**왜 추가했나.** B-5(같은 종 + 같은 장소는 하루 1회)는 오너가 확정한 규칙인데
**이 문서에 문구가 없었다.** 규칙은 있고 사용자에게 할 말이 없으면 개발이 막힌다.
0절 원칙(실패를 사용자 잘못으로 만들지 않는다 · 이유와 대안을 같이 준다)에 맞춰 썼다.
**오너 검토 대상이다.**

| 요소 | 문구 |
|---|---|
| 제목 | 오늘 여기서 만난 꽃이에요 |
| 설명 | 같은 자리에서 같은 꽃은 하루에 한 번 기록해요. |
| 설명 2 | 장소를 옮기면 다시 기록할 수 있어요. |
| 버튼 (주) | 도감에서 보기 |
| 버튼 (보조) | 다른 꽃 찍기 |

**"어제는 됐는데 오늘은 안 되는" 상황이 아니라는 걸 분명히 한다** —
막는 게 아니라 **이미 기록됐다**는 뜻이라서 제목을 부정형으로 쓰지 않았다.
