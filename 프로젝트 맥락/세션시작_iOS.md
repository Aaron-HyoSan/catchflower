## 2. 환경 (설치 완료 · 검증됨)

| | 버전 |
|---|---|
| macOS | 26.5.1 · arm64 |
| **Xcode** | **26.6** (17F113) |
| **Swift** | **6.3.3** |
| 시뮬레이터 | **iOS 26.5** (`iPhone 17`) |
| 최소 지원 타깃 | **iOS 17** — **오너 결정.** E-2 권고(iOS 16)에서 오너가 올렸다 |

**사까마까 유산 규칙을 그대로 따른다** (다른 프로젝트에서 확인된 것):

- **`project.yml`(XcodeGen)이 원본이다. `.xcodeproj`를 직접 수정하지 않는다**
  → 파일을 추가했으면 `cd ios && xcodegen generate`. 안 하면 새 파일이 빌드에 없다.
- **API 키는 소스에 넣지 않는다. 빌드 시점에 주입한다**

빌드·테스트:
```
cd ios && xcodegen generate
xcodebuild test -project CatchFlower.xcodeproj -scheme CatchFlower \
  -destination 'platform=iOS Simulator,name=iPhone 17'
```

**다음 순번은 `구현현황_iOS.md` 6절이 원본이다.** 🔵 **B-4는 더 이상 대기가 아니다** —

"합격선 통과"로 보고했다. **틀린 보고였고 (21) 3절에서 정정했다.**
**기준에 표본 정의가 붙어 있으면 그것도 같이 만족해야 한다.**

**정의는 구현이 아니고, 숫자가 적혀 있으면 구현된 것처럼 보인다.**

⚠️ **"실기기 없이는 못 한다"는 판단을 다시 의심하라.** 4차까지 판별 검증을

사진 3장을 번들에 넣자 시뮬레이터에서 실엔진이 돌았고 **거기서 버그가 나왔다**
(학명 색인이 정답을 버리고 있었다 · 진행.md (19)).
**측정 스크립트로 대체할 수 있는지 먼저 본다** — `ios/Tools/plantnet_measure.py`가 그 예다.

## 4. iOS만의 이점 하나 — 이걸 꼭 쓴다

**Vision 프레임워크로 "이 사진에 꽃이 있나"를 공짜로 판별한다.**
비용 검토 4절의 **호출 절감 48%**가 이걸 전제로 계산돼 있다.
꽃이 아니면 **API를 아예 부르지 않는다** (신발·하늘 사진이 20% 들어온다고 봤다).

**Android에는 이게 없어서 확인 중이다** (공유계약 5절). iOS는 확실히 된다.

## 8. AOS가 알린 것 — **iOS가 붙여야 하는 것** (2026-08-16 · 진행 (78))

**B-4 수집 그룹**을 AOS가 붙였다. 계약 **1-6**이 원본이고 **먼저 그 절을 읽는다.**
사진으로 못 가르는 종 **13종**을 도감 한 칸(**대표종**)으로 접는다 →
도감 **2,057행 · 2,044칸**(🔴 **서로 다른 숫자다** · 계약 1-5).

| iOS가 할 일 | 왜 |
|---|---|
| 🔴 **`공용_적재/build_flowers_json.py`를 다시 돌린다** | iOS `flowers.json`에 **`collect_group_id`가 아직 없다.** AOS가 일부러 안 건드렸다 — 자산은 각 플랫폼이 자기 것을 만든다 |
| 그리드를 **대표종만**으로 그린다 | 안 하면 **채울 수 없는 칸 13개**가 남는다. 사용자는 자기가 못 찍는 줄 안다 |
| 후보 3칸을 **그룹 단위로** 끊는다 | 종으로 끊고 나중에 접으면 화면 09변형 후보가 **2개**로 준다 — **B-4가 후보를 줄인다.** AOS가 실제로 그렇게 만들었고 **테스트는 전부 초록이었다** |
| 저장된 기록을 **한 번 이관**한다(멱등 · 파일까지) | 메모리에서만 접으면 도감 37칸인데 서버 랭킹은 38종을 센다 — **둘 다 그럴듯하다** |

🔴 **순서가 설계다: `후보(종) → 매칭(종) → 접기(그룹)`.**
접기를 후보 만들기 앞에 두면 8월에 서양민들레(3~10월)가 후보에서 빠지고 대표
민들레(3~5월)는 개화월 필터에 걸려 **8월 민들레만 조용히 판별 실패**한다.
개화월은 **일부러 접지 않는다.** 한다/안 한다 표가 계약 1-6에 있다.

⚠️ **DB `flowers` 표에는 `collect_group_id`를 안 넣었다.** 서버 랭킹은
`count(distinct d.flower_id)`로 세므로(0002) 행이 접힌 번호를 들고 있으면 충분하다.
컬럼+INSERT 트리거로 서버에서 막고 싶으면 그건 **마이그레이션 = iOS 몫**인데,
iOS가 1-6을 붙이면 필요 없어지는 것이라 **먼저 정한다**(AOS는 만들지 않았다).

⚠️ 이미 서버에 올라간 행은 앱이 못 고친다(업로드는 INSERT뿐) →
**오너 SQL 1건**이 대기 중이다: `오너_실행/05_B4_수집그룹_이관.sql`.
