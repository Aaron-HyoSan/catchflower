## 2. 환경 (설치 완료 · 검증됨)

| | 버전 |
|---|---|
| macOS | 26.5.1 · arm64 |
| **Xcode** | **26.6** (17F113) |
| **Swift** | **6.3.3** |
| 시뮬레이터 | **iOS 26.5** (`iPhone 17`) |
| 최소 지원 타깃 | **iOS 17** — **오너 결정.** E-2 권고(iOS 16)에서 오너가 올렸다 |

**사까마까 유산 규칙을 그대로 따른다** (다른 프로젝트에서 확인된 것):

- **`project.yml`(XcodeGen)이 원본이다. `.xcodeproj`를 직접 수정하지 않는다**
  → 파일을 추가했으면 `cd ios && xcodegen generate`. 안 하면 새 파일이 빌드에 없다.
- **API 키는 소스에 넣지 않는다. 빌드 시점에 주입한다**

빌드·테스트:
```
cd ios && xcodegen generate
xcodebuild test -project CatchFlower.xcodeproj -scheme CatchFlower \
  -destination 'platform=iOS Simulator,name=iPhone 17'
```

## 4. iOS만의 이점 하나 — 이걸 꼭 쓴다

**Vision 프레임워크로 "이 사진에 꽃이 있나"를 공짜로 판별한다.**
비용 검토 4절의 **호출 절감 48%**가 이걸 전제로 계산돼 있다.
꽃이 아니면 **API를 아예 부르지 않는다** (신발·하늘 사진이 20% 들어온다고 봤다).

**Android에는 이게 없어서 확인 중이다** (공유계약 5절). iOS는 확실히 된다.
