# 캐치플라워 (CatchFlower)

**꽃을 찍으면 AI가 종을 판별해 도감에 모으고, 지도에 남기고, 동네·친구끼리 랭킹으로 경쟁하는 모바일 게임.**

포켓몬GO의 수집 재미를 **실제 자연**으로 옮겼다. 몬스터 대신 **우리나라에 실제로 피는 꽃 200종**이고,
판별은 그림이 아니라 **PlantNet AI가 사진을 보고** 한다. 계절이 지나면 그 꽃은 다음 해까지 못 잡는다.

| | |
|---|---|
| **플랫폼** | Android (API 26+ · 실기기 확인: Galaxy A25 / Android 16) · iOS 동시 개발 |
| **APK 내려받기** | [Releases](../../releases/latest) — `app-debug.apk` |
| **소개 페이지** | [GitHub Pages](../../deployments) |
| **AI 인식** | PlantNet `k-eastern-asia` (4,932종) + ML Kit 온디바이스 1차 필터 |
| **지도** | 카카오맵 SDK (벡터 타일 · 핀 · 클러스터링) |
| **백엔드** | Supabase (Postgres + RLS + 익명 인증) |
| **규모** | main 14,789줄 + 테스트 10,084줄 · 화면 22개 중 19개 동작 · 도감 200종 |
| **테스트** | JVM 409개 (33 클래스) · 계측 47개 · **돌연변이 검증 182건** |

## 실행 방법

**1. APK 설치 (가장 빠름)**

[Releases](../../releases/latest)에서 `app-debug.apk`를 안드로이드 폰으로 내려받아 설치한다.
`설정 → 보안 → 출처를 알 수 없는 앱`을 허용해야 한다.

**2. 소스에서 빌드**

```bash
cd android
cp local.properties.template local.properties   # 키를 채운다 (아래)
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

⚠️ **키가 없어도 앱은 죽지 않는다.** 판별은 Mock으로, 지도·장소명은 꺼진 상태로 돈다
(`AppSecrets` 규칙). 실제 판별을 보려면 `local.properties`에 PlantNet·카카오·Supabase 키를 넣는다.

⚠️ **지도는 키해시 등록이 필요하다.** 카카오 콘솔에 **빌드에 쓴 키스토어의 SHA-1**을 등록하지 않으면
`vector/auth`가 **401**을 준다. 등록 없이 열면 타일이 안 그려진다
(원인이 3가지인데 화면에는 하나로 보인다 — `프로젝트 맥락/진행.md` (37)).

## 설계에서 가장 신경 쓴 것

**1. 유료 API를 함부로 부르지 않는다.** 온디바이스 필터로 92.4%를 미리 걸러내고,
개화월 후보가 0개면(겨울) **네트워크를 아예 타지 않는다.** 호출 직전에 로그를 남겨
**어느 촬영이 과금됐는지 사후에 확인**할 수 있다.

**2. AI 점수를 신뢰도로 착각하지 않았다.** PlantNet 점수는 4,932종에 퍼진 확률이라
**정답도 0.1 근처에 흔히 온다.** 처음 실패 임계값을 0.30으로 뒀더니 **버려진 4장이 전부 정답**이었다
(실기기 실측). 0.05로 내려 1순위 정답률 50% → **80%**가 됐다.
📄 `진행.md` (43)(44)

**3. 실패 화면이 원인을 가리지 않게 했다.** `어떤 꽃인지 알 수 없었어요`는 원인이 세 가지인데
(API가 못 알아봄 / 도감·개화월에서 걸림 / 점수 미달) **화면에는 똑같이 보인다.**
로그 네 줄로 갈라 두고, **그 로그의 내용까지 테스트로 고정**했다 — 로그는 조용해져도 증상이 없다.
📄 `진행.md` (46)

**4. "테스트가 초록"을 증거로 쓰지 않았다.** 초록 249개 상태에서 앱이 죽고 화면에 `null`이 떠 있었다.
JVM 테스트로 **원리적으로 못 재는 층**이 있다는 걸 문서화하고(`AndroidViewModel` 초기화 순서,
기기와 다른 `org.json` 동작), **돌연변이 182건**으로 검사가 실제로 빨개지는지 매번 확인했다.
📄 `진행.md` (31)(38)(41)

## 개발 방식

**Claude Code로 개발했다.** iOS·Android 터미널 2개를 동시에 돌리고
`공유계약_iOS_AOS.md`로 두 플랫폼의 필드명·enum·정책값을 묶었다.

그 기록이 47회차이고, 같은 함정을 두 번 밟은 경우까지 적혀 있다.
