# 캐치플라워 (CatchFlower)

꽃을 찍으면 AI가 종을 판별해 **도감**에 모으고, **지도**에 남기고,
**동네·친구**끼리 시즌 랭킹으로 경쟁하는 모바일 게임.

**현재 상태 (2026-08-04): 기획 완료 · 개발 환경 구축 완료 · 앱 코드 착수 전**

## 확정된 것

| 항목 | 결정 |
|---|---|
| **A-1 AI 인식** | **PlantNet** (무료 일 500건 → DAU 100명 넘으면 Pro 연 €1,000) |
| **A-3 지도** | **카카오맵** (REST 키 3용도: 지도·장소명·행정구역) |
| **E-1 플랫폼** | **iOS · Android 동시 개발** (터미널 2개) |
| 인식 필수 구현 | **개화월 하드 필터** — PlantNet이 79,047종에서 골라 11월에 "벚꽃"이 올 수 있다 |
| 백엔드 권고 | Supabase (랭킹이 SQL에 맞다) |

## 미확정 — 오너 대기

**키 3개 (전부 0원):** PlantNet 무료 계정 · 카카오 REST 키 · Supabase 계정
**그리고 B-3 답변** (권고: 항상 후보 3개 + 난이도별 임계값 + 어뷰징 가드 3종)

**★ 14개가 남았지만 전부 "답하면 끝"이고, 개발을 막지 않는다.**
`FlowerRecognizer` 인터페이스 뒤에 벤더를 숨기고 Mock으로 시작하면
**앱의 80%(인증·도감·지도·랭킹·친구)를 지금 만들 수 있다.**

## 규모

| | 수 |
|---|---|
| 화면 | **22개** (+ 흐름도 2장) |
| 도감 | **200종** — 봄 72 · 여름 92 · 가을 30 · **겨울 6** |
| 희귀도 | 흔함 88 · 보통 102 · **귀함 10** |
| AI 난이도 | 하 33 · 중 116 · **상 51** ← 실측 대상 |
| 문구 항목 | 엑셀 인벤토리로 정리됨 |

**겨울 6종이 시즌 설계를 바꿨다.** 6개월로 자르면 한 시즌 후반 3개월이 죽어서
**3~8월 / 9~11월 + 12~2월 휴지기**를 권고했다 (B-1).
