# 실사진 픽스처 (시뮬레이터 전용 · 3장 268KB)

**왜 이게 필요한가.** 시뮬레이터에는 카메라가 없어서 픽스처가 빈 `Data()`였다.
그래서 `PlantNetRecognizer`는 **실기기 없이는 한 줄도 실행되지 않았다** —
보낼 사진이 없으니 항상 Mock으로 우회했다. 이 사진들이 그 벽을 없앤다.

**이건 Mock 픽스처를 대체하지 않는다.** Mock 픽스처(`fixture_*.jpg`)는
점수가 고정이라 UI 테스트가 결정론적이다. 이 사진들은 네트워크를 타므로
점수가 흔들리고 쿼터를 쓴다 — **손으로 눌러 보는 용도**다.
자동 테스트는 계속 Mock을 쓴다.

| 파일 | 출처 클래스 | 실측 1순위 | 밟는 경로 |
|---|---|---|---|
| `real_sunflower_high.jpg` | sunflowers | `Helianthus annuus` **0.994** | 확정 (난이도 하 임계 0.60 통과) |
| `real_sunflower_low.jpg` | sunflowers | `Helianthus annuus` **0.570** | 애매 (0.60 미달 → 후보 3개) |
| `real_dandelion_faint.jpg` | dandelion | `Taraxacum sect. Taraxacum` **0.112** | **정답인데 판별 실패** — B-3 floor 문제를 눈으로 본다 |

해바라기를 고른 이유는 두 개다. **개화월이 7~9월**이라 지금(8월) 하드 필터를 통과하고,
**난이도가 `하`**라 임계값이 0.60이어서 확정·애매 두 경로가 한 종으로 갈린다.
⚠️ **10월이 되면 해바라기가 개화월 필터에 걸려 이 픽스처가 판별 실패가 된다.**
그건 버그가 아니라 A-1 하드 필터가 옳게 도는 것이다 — 그때는 제철 꽃으로 바꾼다.

## 출처와 라이선스

**TF-flowers** 데이터셋 (`/private/tmp/flower_photos`, Android 터미널이 내려받아 둔 것).
원본은 Flickr 사진들로 **CC-BY** 계열이며 Google이 ML 예제용으로 배포한다.
→ **개발 중 테스트 용도로만 쓴다. 앱에 표시하거나 출시 번들에 넣지 않는다.**
`#if DEBUG`로 묶여 있어서 Release 빌드에는 코드 경로가 없다.

라이선스가 명확한 사진이 필요해지면 국립생물자원관 공공누리 이미지로 교체한다.
